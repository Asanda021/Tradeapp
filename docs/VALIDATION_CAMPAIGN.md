# Tradeapp validation campaign

This campaign separates automated verification from real-world evidence.

Gates 1-10:
1. Sandbox exchange connection
2. Real market-data stability
3. Long-running paper trading
4. Long-running shadow trading
5. Multi-market backtest with real data
6. Walk-forward + Monte Carlo with real data
7. Local AI benchmark using an installed local model
8. Multi-source news intelligence
9. Network/crash/order recovery
10. Production security audit

Unit tests never count as real-world evidence. Real validation is opt-in and requires the appropriate sandbox credentials, network access, or physical device evidence. Live trading remains locked.
